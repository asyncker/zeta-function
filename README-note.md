Toy model zeta function

```math
\frac{1}{1 - 2^{1 - z}} = \frac{\zeta(z)}{\eta(z)}
```

Bose-Einstein (-1):
```math
\frac{(1 - e^{t - z})'}{(1 - e^{t - z})} = \frac{+1}{e^{z - t} - 1}
```

Fermi-Dirac (+1):
```math
\frac{(1 + e^{t - z})'}{(1 + e^{t - z})} = \frac{-1}{e^{z - t} + 1}
```
